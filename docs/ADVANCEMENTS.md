# Достижения Mage's Legacy

Одна вкладка в стандартном меню достижений (L). Все выдаёт сервер за подтверждённое действие (критерий `mages_legacy:deed`);
сохраняются и отзываются штатно (`/advancement`). Достижения расы засчитываются только этой расе, в тестовом режиме `nocooldown` — никакие.
Наград, кроме записи и уведомления, нет. В чат сервера пишутся только крупные (отмечены ★).
При входе выдаётся то, что доказывают сохранённые данные (раса, уровни, таланты, Пробуждения, испытание мастерства, Материнская грибница, выросшие нити).

## Общий путь

| Достижение | Тип | Условие |
|---|---|---|
| Mage's Legacy — Наследие магии | обычное | Начало наследия: выбрать расу |
| Пробуждение дара | обычное | Достичь 5 уровня расы и обеих базовых способностей |
| Первый выбор | обычное | Достичь 10 уровня расы и изучить талант второго яруса |
| За пределами одной школы | обычное | Изучить перекрёстный талант |
| Первое пробуждение | цель ★ | Получить первое Пробуждение расы |
| Испытание мастерства | цель ★ | Пройти испытание мастерства своей расы |
| Двойное наследие | испытание ★ | Открыть второе Пробуждение |
| Вершина эволюции | испытание ★ | Достичь 50 уровня расы |
